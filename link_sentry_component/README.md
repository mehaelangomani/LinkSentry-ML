# LinkSentry Custom Component

Streamlit custom component wrapping the original LinkSentry frontend (vanilla HTML/CSS/JS) for phishing URL detection.

## Structure

```
link_sentry_component/
├── frontend/                 # Component frontend source
│   ├── index.html           # Original frontend with Streamlit protocol
│   ├── package.json
│   ├── vite.config.ts
│   └── src/
│       └── (empty - all in index.html)
├── link_sentry_component/   # Python package
│   ├── __init__.py
│   └── component.py
├── dist/                    # Built frontend (generated by npm run build)
│   └── index.html
├── pyproject.toml
└── README.md
```

## Building the Frontend

```bash
cd frontend
npm install
npm run build
```

This outputs to `../dist/` which is included in the Python package.

## Installing

```bash
pip install -e .
```

## Usage in Streamlit

```python
from link_sentry_component import link_sentry_component
from model import predict_url

# In your Streamlit app
component_value = link_sentry_component(result=st.session_state.get("last_result"))

if component_value and component_value.get("action") == "scan":
    url = component_value["url"]
    with st.spinner("Analysing URL..."):
        result = predict_url(url)
        st.session_state.last_result = result
        st.rerun()
```

## Communication Protocol

**Python → Frontend (via props):**
```json
{
  "result": {
    "label": "phishing|legitimate",
    "confidence": 98.51,
    "probabilities": {"phishing": 98.51, "legitimate": 1.49},
    "error": null
  }
}
```
Or `{"result": null}` for empty state.

**Frontend → Python (via setComponentValue):**
```json
{
  "action": "scan",
  "url": "https://example.com",
  "requestId": 123
}
```
